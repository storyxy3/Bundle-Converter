# Native chain restructuring (task U)

Editor tooling that restructures PJSK secondary chains into native Gakumas chains. Survey outputs (presets.json etc.) are regenerated by the scripts below and are not kept in the repository (hundreds of MB).

Inputs and isolation: project is a copy of live-urp-native Assets/Packages/ProjectSettings/Library; no runtime source modifications. Packages/manifest.json points at the same local URP fork. Unity requires DOTNET_USE_POLLING_FILE_WATCHER=1 on this server to avoid the inotify instance limit.

Survey:
  /work/gakumas/tools/venv/bin/python survey/extract.py
  python3 survey/presets.py
The Unity NativeRigSurvey.Run entry point emits transform positions/settings; serialized reference lists in its JSON are unreliable. extract.py resolves the actual serialized native references instead. presets.py joins both by bundle and bone name. Native model-space coordinates differ between hair and body parts; chain lengths use within-part distances only.

Export:
  ulimit -n 65536
  DOTNET_USE_POLLING_FILE_WATCHER=1 unshare -n xvfb-run -a -s '-screen 0 1280x720x24' /work/.toolchains/unity-6000.0.77f1/Editor/Unity -batchmode -force-glcore -quit -projectPath /work/motion-bake/task-U/project -executeMethod NativeActorExport.Run -logFile /work/motion-bake/task-U/export.log
  /work/gakumas/tools/venv/bin/python converter/link-native-shader.py
Stage three actor bundles plus task S's neutral resources using task S converter/stage-native.py, keeping the original motion bundle. Captures use capture-native.sh SECOND VARIANT (native/before/after). Never stage while capturing.

Second character:
  /work/gakumas/tools/venv/bin/python miku/export_actor.py
Run MikuRestructure.Run in the same Unity invocation pattern. It loads original Miku 21/0001 ladies_s body and face, adds native secondary-bone authoring and calls the identical NativeChainRestructure.Apply function. This produces a prefab and rest-error report, not a full native Humanoid Miku actor export.

Measurements:
  python3 metrics.py
  /work/gakumas/tools/venv/bin/python mesh-metrics.py
These summarize captured data, not tests or solver substitutes. Bone length belongs to the current bone's parent segment. Positional second differences include intentional animated motion. Thigh capsule penetration only measures vertices for which every influencing transform was recorded; missing coverage is explicitly counted. Capsule penetration is not triangle-to-triangle thigh intersection.

Final native-motion captures:
  for variant in native before after; do for second in 28 45 71; do bash capture-native.sh "$second" "$variant"; done; done
Paired history measurements (same staged content, no staging during these runs):
  for variant in native before after; do
    U_CAPTURE_LABEL="$variant-short" U_SEEK_SECONDS=1 U_STOP_SECONDS=2 bash capture-native.sh 28 "$variant"
    U_CAPTURE_LABEL="$variant-long" U_SEEK_SECONDS=5 U_STOP_SECONDS=2 bash capture-native.sh 28 "$variant"
  done
  python3 seek-metrics.py
  python3 figures.py

Complete second-character native export:
  Run MikuPrepare.Run with the same Unity command pattern, then run NativeActorExport.Run with:
    S_SWING_BUNDLE=/work/motion-bake/task-U/miku/prepared/miku.bundle
    U_REST_BUNDLE=/work/motion-bake/task-U/miku/prepared/miku.bundle
    U_SOURCE_JSON=/work/motion-bake/task-U/miku/source.json
    U_ACTOR_OUT=/work/motion-bake/task-U/miku/actor-out
    U_ACTOR_ASSETS=Assets/NativeActorMiku
    U_REPORT_DIR=/work/motion-bake/task-U/miku/native
  Shader linkage:
    U_LINK_OUTPUT=/work/motion-bake/task-U/miku/actor-out U_LINK_METADATA=/work/motion-bake/task-U/miku/materials.json /work/gakumas/tools/venv/bin/python converter/link-native-shader.py
  Stage these three actor bundles and task S's neutral resources with stage-native.py into content-miku, then:
    U_CAPTURE_LABEL=miku bash capture-miku.sh 28 after
MikuPrepare joins the duplicate face/body torso and separates hair triangles by their secondary-bone influence. NativeChainRestructure and NativeActorExport are shared unchanged between character invocations; input/output paths are environment settings. Miku materials reuse the native body material contract with Miku primary textures; the exact face/hair shader-type mapping and secondary texture conversion are not completed.

Project-copy prerequisites (inside task-U; original inputs remain read-only):
  mkdir -p work/il2cpp-3.5.3
  ln -s /work/gakumas/work/il2cpp-3.5.3/DummyDll work/il2cpp-3.5.3/DummyDll
  Packages/manifest.json in project must point its four URP file dependencies at /work/gakumas/work/urp14-fork-live.
For the Unity survey, substitute -executeMethod NativeRigSurvey.Run in the export command. For the complete staged rest-skin measurement, substitute -executeMethod NativeRestMeasure.Run -logFile /work/motion-bake/task-U/global-rest.log.

Final evidence:
  python3 manifest.py
  patch --batch --dry-run -p1 -d converter-base < converter.patch
Generated datasets and Unity assets are retained locally; source commits contain the editor changes and small offline scripts. The final content-native/content-miku manifests and artifact-manifest.json identify the exact bundles used. Intermediate captures are retained under restructured-v1 and helpers-v2; these do not establish final acceptance.
